# 🎹 Swaraa

### *Bridging Tradition with Technology through Indian Classical Music*

Swaraa is a modern, browser-based digital harmonium that recreates the authentic experience of playing a traditional Indian harmonium while leveraging cutting-edge web technologies. Built with **Next.js**, **TypeScript**, and the **Web Audio API**, Swaraa delivers studio-quality sound, an intuitive interface, and powerful learning tools for musicians, students, and music enthusiasts.

Whether you're learning your first **Sa Re Ga Ma**, practicing classical ragas, or performing with a MIDI keyboard, Swaraa provides a seamless and immersive musical experience directly from your browser.

# 🚀 Quick Start

## Prerequisites

* Node.js 18+
* npm / yarn / pnpm / bun
* Browser supporting Web Audio API

---

## Installation

```bash
git clone https://github.com/BCSAKETH/Swaraa.git

cd Swaraa

npm install

npm run dev
```

Open:

```
http://localhost:3000
```

---

## Production

```bash
npm run build

npm start
```
